# RAPD 调整方案（2026-10-25）

> 二次复核更正：本文保留为历史版本，不能直接作为实施协议。教师优势标签不等于可恢复性，类别 r 均值不等于逐像素范围，AUC 不能证明路由收益，旁路失败不能证明 RGB 不可达。最新有效建议见 `RAPD_调整方案_复核与更正_2026-10-25.md`；与其冲突的强结论以更正说明为准。

**背景**：`CVPR2027_KD_审核报告_2026-10-25.md` 的结论是——RAPD 的"可恢复性加权 + 保守回退"在 MFNet 上无效，且是**定义层面**的无效（r∈[0.829,0.929] ⇒ ε≤0.086）。
**本文回答两个问题**：这项 RAPD 工作该怎么调整？要不要改进 RAPD 这套方案？
**方法**：结论全部建立在报告里已实测的数字上（同批同协议重测、逐像素配对表、r 逐类分布、class 权重精算），不引入新的假设。

---

## 1. 一句话结论

**不要改进 RAPD 的公式，要改它的角色。**

* 继续调 `ε_max / gate / rare_protect` 是无效劳动——这些旋钮的活动空间被 r 的动态范围锁死在 8.6% 的概率质量里；
* 但"可恢复性"这个概念还有救，救法是把它从**权重旋钮**改成**有 AUC 的预测器 + 监督通道的路由器**；
* 如果连这个也失败，就诚实地转成一篇"特权证据为何无法蒸馏"的分析论文——那也是真结果。

---

## 2. 为什么不能靠调参救（三条硬约束）

| 约束 | 数字 | 含义 |
|---|---|---|
| 作用幅度 | ε = ε_max(1−r) ≤ 0.086 | 保守目标与教师分布最多差 8.6% 概率质量，比 label smoothing(0.1) 还小 |
| 权重结构 | KL 的 83–93% 是纯 KD | 方法在数值上≈均匀 KD 的恒等变形 |
| 实测差 | RAPD v2 59.70 / CE 59.82 / Uniform 59.63；Δ∈[−0.18, +0.07] | 三者两两不可区分；三 seed sd 0.54 大于任何一档差 |

**更根本的一条**：降低蒸馏强度只能"不伤害"，不能"给新信息"。所以这一族方法在动机所指的失败模式（夜间 person 缺口 18）上，收益上界天生≈0。实验测到的 −0.12 不是运气问题。

---

## 3. RAPD 错在哪两个假设

| 假设 | 当初的理由 | 现在被什么否掉 |
|---|---|---|
| H1：**特征可预测 ⇒ 证据可迁移** | r 高说明学生特征里"有"教师的信息 | r 类间跨度仅 0.101；person 的 r=0.865 排第 4，而 person 恰是唯一"教师强、学生学不到"的类。探针测的是"1×1 卷积能否回归出教师特征方向"，不是"这条证据能否用于分类" |
| H2：**不可恢复 ⇒ 就少蒸馏** | 避免逼学生复制看不到的东西（防幻觉） | 少蒸馏 = 在那些像素上关掉监督 ≈ 保持原样，不产生增益。四套 KD 配置夜间 person 全停在 47–48，教师 65.74 |

**调整必须针对假设，不是针对公式。**

---

## 4. 三条可选路线

| | 做法 | 需要的补充 | 上限 / 风险 |
|---|---|---|---|
| **A 降级为诊断** | RAPD 不再当方法，改当"测量特权信息可迁移性"的工具；写机制性负结果 | 第二数据集（DeLiVER）+ ECE | 素材已有 ~80%，但纯负结果在 CVPR 接受度低，且 DeLiVER 在 23 天内很紧 |
| **B 重做度量 + 换角色**（推荐主线） | r 换成**用结局校准**的可恢复性预测器；r 决定"用哪种监督"而不是"蒸馏多强" | 一个固定的参照学生（已有 CE 500ep）+ 按图像 cross-fit + AUC 报告 | 可能第一次让"可恢复性"这个词有内容；若 AUC≈0.5 则此路也死，但这是一个**明确的**结论 |
| **C 换被传递的量** | 承认 logit 到不了；改传特征/区域级监督，或用热成像高响应区做可见性掩码（仅训练期） | 半天可行性探针即可判定 | 唯一可能真正动夜间 person 的路线；决定这项工作是"方法论文"还是"分析论文" |

**推荐：B 为主线，C 的半天探针并行判定，A 作兜底。** 不是三选一，因为三者回答的是三个不同问题：B 回答"这个度量有没有用"，C 回答"有没有涨点故事"，A 回答"最坏情况能不能投"。

---

## 5. 核心实验设计：把 r 重做成"可验证的量"

这是整个调整里最容易做错的一步，协议必须事先写死。

### 5.1 标签与特征

* **标签**：`y = 1[教师argmax = GT ∧ 学生argmax ≠ GT]`，即"教师对、学生错"的像素。这就是报告 §4.7 里那张四格表的第二列（夜间 person 约 22%）。
* **特征**：学生该像素的特征向量（decoder 最后一层）+ 可选少量师生分歧统计（教师熵、学生熵、两者 top-1 差值）。
* **固定参照学生**：用已完成 500 epoch 的 CE checkpoint（`i_rgb_s3407/last.pth`，可复现）定义标签，**不要让标签跟着训练中的学生一起漂**。

### 5.2 防泄漏（这一步决定结论是否成立）

* 按**图像**做 5-fold（不是按像素）；
* 探针只在 4/5 的图像上拟合，在第 5 折上评分并报 AUC；
* 训练时使用的 r 必须来自**未见过的图像**（否则等于把答案喂给学生）。

### 5.3 必须报的对照（否则 AUC 再高也没有意义）

| 基线 | 为什么必须报 |
|---|---|
| 学生熵 / margin | 这是"不确定性"能给出的信息。若可恢复性分数不能**超过**熵基线，那 r 只是学生置信度的换皮，方法没有新内容 |
| 教师熵 | 排除"教师自己犹豫"的平凡解释 |
| 类别先验 | 排除"只是认出了这是 person 类" |

### 5.4 判据（事先写死，避免事后解释）

| AUC（vs 熵基线） | 判定 | 下一步 |
|---|---|---|
| ≥ 0.70 且显著高于熵基线 | 可恢复性**可预测**且**有新信息** | 进入 §6 的通道选择实验 |
| 0.60–0.70 | 弱信号 | 只做"分通道"不做"分级"，降级为工程技巧 |
| < 0.60 或打不过熵基线 | 可恢复性**不可从学生特征预测** | 放弃加权这一支，全部资源转 C |

---

## 6. 若 AUC 通过：从"调强度"改成"选通道"

RAPD v3 的形式不是 `L = r·KL_t + (1−r)·KL_u`，而是：

```
对每个像素，按可恢复性分数选一种监督：
  r 高        → logit KD（教师分布可信）
  r 中        → 特征模仿（方向可信、分布不可信）
  r 低        → 不监督（或只做一致性正则），不假装有监督
```

这不是把三个损失加权相加，而是**互斥路由**——因为"软化目标"这条路已经证明无效（§2），继续在同一个量上做线性混合只会重复 RAPD 的失败。

**检验方式**：在"教师对、学生错"的夜间 person 像素上，对比三种监督的边际收益（同一批像素、同一 seed、同一预算）：

| arm | 监督形式 | 预期读数 |
|---|---|---|
| 1 | logit KD | 已测：CE 47.91、classbalance 48.81 → 基本不动（教师 65.74） |
| 2 | 特征模仿（proj 后余弦 / 区域对比） | 若 > 51，说明缺的是表征入口 |
| 3 | 不监督（对照） | 用来确认前两者不是"少扰动"的假收益 |

## 7. 排期（距 11-17 还有 23 天）

| 优先级 | 任务 | 工期 | 资源 | 依赖 |
|---|---|---|---|---|
| P0 | 补回可验证性：重训 `p1_ce`/`p1_classbalance`、发布 checkpoint、`results/protocol/*.json` 入库、修 `data` 自指符号链接与硬编码路径 | 半天 | 2 卡 | — |
| P1 | `CE` × 3 seed + `cbce` × 3 seed + `classbalance` × 3 seed（决定性对照，共 9 次） | 1 天 | 2 卡 ≈ 27 GPU·h | P0 |
| P2 | 重做 r：cross-fit AUC + 熵基线 | 2–3 天 | 1 卡（探针很小） | P0 |
| P3 | 通道选择实验（logit / 特征 / 不监督） | 2–3 天 | 2 卡 | P2 判据通过 |
| P4 | 特权特征旁路探针（仅训练期注入热特征） | 半天 | 1 卡 | 可并行 |
| P5 | 若 A 路线：DeLiVER 教师 + 2 配置 | 2 天 | 2 卡 | 数据可得性未验证 |

**为什么 P1 排在最前**：它只花 1 天，却决定后面 20 天是在做"方法改进"还是在做"负结果论文"。现在两条路同时在走，是最大的风险。

## 8. 事先写死的 stop / go

| 观察 | 结论 | 动作 |
|---|---|---|
| `cbce` 与 `classbalance` 差 < 0.5 | "特权蒸馏"归零，只剩 loss reweighting | 不要把 class-balance 包装成 RAPD；论文故事改写 |
| AUC < 0.6 且打不过熵基线 | 可恢复性不可预测 | 放弃 RAPD 加权支线；资源全给 C 与 A |
| 特征旁路后夜间 person < 53 | 该证据在 RGB 上确实不可达 | 负结论彻底闭环，走 A（这是更强的论文结果） |
| 特征旁路后夜间 person ≥ 55 | 缺的是表征入口，不是监督信号 | 走 C，重写方法（训练期特权特征，推理纯 RGB） |

---

## 9. 三条不要做

1. **不要再扫 `ε_max / rare_protect / gate` 的超参**——活动空间被 r 锁在 8.6%，属于无效搜索。
2. **不要把 class-balance 的结果写成 RAPD 的成果**——它连教师都不需要（cbce 才是公平对照），混在一起会被审稿人一眼看穿。
3. **不要在 cbce 没跑之前写"+3 点"**——那是拿一个比自有 CE 低 1.53 的参照点算出来的。
