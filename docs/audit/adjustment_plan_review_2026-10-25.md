## 2. 首先纠正：当前 RAPD 未证明有效，不等于证明永远无效

此前同批固定 checkpoint 比较中，RAPD v2 与 CE 的差很小，图像级 bootstrap 区间跨零。这支持“**在这次受测设置下没有检出可靠增益**”。

它不证明：

- 真实效应严格为零；
- 所有超参数都不可能改进；
- 所有可恢复性感知方法都失败；
- 纯 RGB 学生已经达到信息论上限。

非显著不是等效性证明。若区间仍允许实际有价值的正收益，结论应是证据不足，而不是“判死”。此外，图像 bootstrap 不含训练随机性的全部不确定性。

因此可合理停止大规模盲目扫参，但理由是目前投入产出证据弱、机制未被验证、对照缺失，而不是我已证明其不可能成功。

## 3. 数学复核：之前的 8.6% 上界论证有两处错误

### 3.1 按类别均值不是逐像素范围

实际读取 `audit_repo/results/diag_uniform/r_by_class.json`：`r.all` 提供每类一个统计值，另有像素计数；没有逐像素分位数、极值或方差。

`audit_repo/semseg/kd/probe.py:31` 的输出本身是逐像素 r。此前把类别均值的最小值与最大值当成所有像素范围，是错误的。

即使每类均值都很高，也可能包含少量低 r 像素。这些像素恰可能是困难区域。没有直方图、分位数和按教师正确性分层的分布，不能判断低 r 区域是否存在、是否被门控有效选择。

另一个限制：这个 JSON 标注的是 uniform 运行的探针，不能直接充当所有 RAPD 运行、所有训练阶段的 r 分布。

所以必须撤回“任意像素的回退幅度不超过 8.6%”“所有旋钮被锁死”“均值跨度小证明 r 没有判别力”的论断。类别均值只提供需要检查饱和或弱区分度的线索。

### 3.2 实际 logit 梯度还有第二次衰减

代码依据：`audit_repo/semseg/kd/losses.py:144` 将 r detach；第 153 行定义 eps；第 173 行构造 p_u；第 182 行混合两个 KL。

固定当前一步的教师、先验、detach 后的 r 和门控系数，设学生温度概率为 q：

```text
p_u = (1-eps) p_t + eps pi
L = r KL(p_t || q) + (1-r) KL(p_u || q)

p_eff = r p_t + (1-r) p_u
      = (1-alpha) p_t + alpha pi
alpha = (1-r) eps
```

该混合损失与 `KL(p_eff || q)` 只差当前一步与学生 logits 无关的常数。包括温度平方后的 logit 梯度为：

```text
d L / d z_s = tau (q - p_eff)
```

无额外门控时：

```text
eps = eps_max (1-r)
alpha = eps_max (1-r)^2
```

若开启分歧门或稀有类保护，alpha 还乘以代码中相应的 detach 系数。故“回退被二次衰减”是可靠的结构观察，而“二次衰减保证没有精度增益”不是。

以 person 类均值 `r=0.8654395582614538`、`eps_max=0.5` 代入常数 r，仅作说明，alpha 约为 0.00905。**这不是实测平均 alpha**，因为均值的平方不等于平方的均值。

如果 r 属于 [0,1]，只知道均值 mu，则无额外门控时：

```text
eps_max (1-mu)^2 <= E[alpha] <= eps_max (1-mu)
```

对该均值，区间约为 0.00905 至 0.06728。这个计算只对应上述数据统计与无门控假设，不能替代训练中日志。实际点级通用上界是 eps_max，而不是此前声称的 0.086。

### 3.3 梯度变化小，也不意味着准确率收益上界小

目标分布扰动、参数训练轨迹、最终决策边界和 IoU 不是同一个量。小的正则或目标改变可以改变优化轨迹；不能直接把概率质量比例当作 mIoU 增益上限。

若包含特征项，`losses.py:188` 之后还有额外梯度，不包含在上述 logit 等价推导中。总训练目标还有监督 CE。此前将整个方法概括成“恒等于 uniform KD”也不严谨。

正确的诊断应记录：实际 alpha 的分位数、按类/昼夜/教师正确性分层的分布、目标距离，以及 KD 与 CE 的实际梯度范数或冲突。若 alpha 接近零，只能说回退作用弱；仍需无回退对照确定它是否影响性能。

## 4. 为什么“教师对、学生错”不是可恢复性

定义 `a=1[teacher_correct AND student_wrong]`，它回答的是：当前固定学生在哪些像素落后于教师。

它不回答：经过某种监督后，纯 RGB 学生能否在未见图像上改善。

两个反例即可区分：

1. RGB 有行人轮廓，只是当前学生没学好。教师对、学生错，可能通过蒸馏纠正。
2. RGB 中缺乏足以区分的视觉线索，热成像提供了额外证据。教师对、学生错，但复制该样本的教师输出可能不泛化。

两个情形的 a 完全相同，却对应不同学习收益。因此训练一个 a 的高 AUC 预测器，最多是预测教师优势事件，不是验证“可恢复性”。

还存在语义方向冲突：若高分代表教师优势/学生困难，高分并不自动意味着“最适合 logit KD”；低分也包含“师生都正确”的像素，不能一律理解为不可恢复并停止监督。

“某类教师优势大，所以其 r 应最低”也不是必然。教师优势可能来自学生优化不足，而不是不可恢复；类别均值不能决定这个命题。

建议暂时使用三个明确名称：

- 特征一致度：现有余弦探针实际测的量。
- 教师优势分数：预测 a 的模型实际测的量。
- 蒸馏收益：换监督后、在未见数据上实际减少的错误或损失。

不要在没有证据时把三者都叫 r。

## 5. AUC 与防泄漏需要怎样重写

### 5.1 AUC 不是训练干预收益

AUC 评价事件的排序；并不评价概率校准，更不评价“按分数路由后学生是否改善”。全局 AUC 还可能主要来自区分类别、昼夜或背景，而非同类困难区域。

若保留优势预测器，应报 AUROC、AUPRC（同时报正例率基线）、校准或 Brier 指标、分组内指标。区间以图像/场景为统计单位，不把相关像素当独立样本。

此前的 0.6、0.7 阈值不是公认的可恢复性阈值，应撤回其生死判据含义。预测器失败也只说明当前标签、特征、模型与数据不足，不能证明 RGB 原则上无法预测该量。

### 5.2 cross-fit 的适用边界

训练期使用 GT 判定教师是否正确，本身是合法监督，不是因为看到了 GT 就发生泄漏。`task_aware.py:82` 已经这样做。

泄漏问题在于：用测试标签训练预测器、挑阈值、选分支，再在同一测试集报告改进。旧方案没有清楚说明 cross-fit 是在哪个 split 上做的，存在把既有评测集继续当训练资料的风险。

更稳妥的协议：

- 最终评测集只报告结果，不用于学习掩码或调门槛。
- 若需拟合优势模型，在训练集内做图像/场景分组划分。
- 固定参照 CE 学生能减少标签漂移，但其训练内错误可能低估真实困难。若目标是泛化错误预测，需要基础学生的 out-of-fold 预测或独立诊断集；只对预测器 cross-fit 不会消除基础模型见过图像的影响。
- 若跨时间使用预测器，应检查固定分数对学生早、中、晚期的适用性。
- 若预测器仅用于训练，允许教师信息作为输入，但它不再是“RGB 可预测性”的证据；若预测器用于部署，就必须只依赖 RGB 和学生量，并计入部署成本。

## 6. 路由器目前没有可靠依据

此前的“高分 logit / 中分特征 / 低分无 KD”隐含三个未验证假设：存在通道收益异质性；优势分数预测这种异质性；三个通道按分数具有固定单调顺序。

一个预测当前错误的模型不能自动成为干预策略模型。必须先检查固定监督方式是否存在稳定的不同收益，再验证某个路由分数能否优于不路由、随机路由或简单规则。

特征监督本身也有风险：它可能强迫学生拟合 RGB 无法解释的热成像细节，发生负迁移。应优先采用任务相关投影或关系约束，并匹配模型容量与预算；不能预设特征比 logit 更可迁移。

任何“真实通道收益标签”都依赖训练干预、模型状态和优化预算。单步梯度方向可作辅助诊断，但不等于训练结束后的泛化收益；有限评测像素的前后正确性变化也不能直接当作通道因果收益。

因此路由器应是后续探索，不应成为当前主线。没有固定基线，不值得先开发复杂路由架构。

## 7. 为什么热特征旁路不能闭合不可能性结论

分三种情况：

| 旁路设置 | 结果实际说明什么 |
|---|---|
| 训练和测试都给真实热特征 | 模态增强/特权诊断模型有效，不是纯 RGB 蒸馏有效 |
| 训练给真实热特征，测试直接移除 | 成败混有输入分布偏移与旁路依赖，不能证明 RGB 可达/不可达 |
| 用 RGB 预测辅助特征，部署也只用 RGB | 属于合法 RGB 推理方法；只有部署条件下的实测增益才算成功 |

训练期旁路容易让模型走捷径而忽视 RGB；测试移除后的失败可能只是这条捷径失效。即使随机屏蔽旁路、蒸馏回 RGB 分支，也必须独立验证最终 RGB 分支。

因此撤回“低于 53 则不可达”“超过 55 则根因一定是表征入口”等结论。这些都是没有功效与对照支持的门槛。

信息论能给出的正确约束是：纯 RGB 的最优决策只能依赖 p(y|x)，有特权信息的模型能依赖 p(y|x,z)。训练期知识可能改善有限样本学习，却不能保证复现 z 对某个测试样本提供的独有证据。

但一个 CE 模型没学会，不意味着它等于 RGB 的最优分类器；一次旁路失败也不能估计这个最优上限。

## 8. “少蒸馏的收益上界为零”也必须撤回

拒绝有害教师目标可以减少负迁移，改变样本间梯度分配，让学生更有效地学习已有 RGB 信号。收益不要求凭空增加测试输入的信息。

代码中的总目标仍保留监督 CE；弱化 KD 并不意味着该像素完全没监督。先前将“不增加输入信息”等同于“不可能改善精度”，混淆了信息上限与有限模型的估计/优化误差。

同理，软标签可能通过正则化改善泛化；不能因其没有新传感器信息就排除它。文献 [1] 明确讨论了软目标的正则作用。本项目是否受益，必须由实验回答，不能直接引用文献当作成功保证。

## 9. 类别加权对照：重要但不充分

类别加权 CE 回答“普通监督重加权能否解释增益”；类别加权 KD 与它不同，还包含软目标、温度和不同的归一化。二者接近不证明热知识贡献严格为零；二者不同也不自动证明增益来自热成像。

最低限度应区分：

- 无教师的类别加权 CE；
- 同样 KD 权重和归一化的教师无关软目标正则；
- 同样配置的 RGB 教师 KD；
- 对齐 RGB+热教师 KD。

后三者用于分离软目标正则、普通教师作用与额外模态作用。RGB 教师控制也可能混有教师质量差异，应报告教师质量、构建预算与解释边界。

如果测试错配热成像，必须区分“训练好的教师对错配输入性能下降”和“学生训练采用错配教师目标后表现如何”。前者证明依赖模态配对，不直接证明蒸馏收益由它带来；错配还可能制造分布外输入，只能作诊断而非唯一归因对照。

同一训练批次的 CE 才是主比较参照。此前把旧批 CE 或验证选出的 best 直接替换进 P1，不能用来纠正 P1 的效应量；那只说明跨批差异值得复核。不能从少数跨代码/机器差值估出训练方差，更不能保证三个 seed 已具备足够检验功效。

此前将 class_weight × frequency 的份额称为“KD 梯度质量占比”也不精确：那只是静态损失权重质量。真实梯度还依赖预测残差、归一化、掩码与模型 Jacobian，不能由像素占比直接解释各类 IoU 的变化。

## 10. 更可靠的最小实验路线

### 阶段一：先锁定问题与证据，不做新路由

1. 冻结代码版本、数据划分、教师 checkpoint 和主指标。最终所有方法测试时只有 RGB。
2. 查找已有 P1 日志、checkpoint、逐图 JSON 和备份；有则校验恢复，无则记录缺口并重建，不把重新训练称为复现了丢失的原轨迹。
3. 主指标建议预注册 foreground mIoU；夜间 person IoU 为关键次指标；同时报告 official mIoU、逐类结果和 RGB-only 部署开销。若研究问题是夜间行人，明确它是主要条件性目标，而非事后挑最好的类。
4. 先复核 CE 与 uniform KD 的同批实现、初始化、数据顺序、增强、dropout 及计算预算。损失系数和允许调参预算对各分支公平。

### 阶段二：小规模机制筛选

| 分支 | 目的 | 比较要求 |
|---|---|---|
| CE | 基础参照 | 同批纯 RGB |
| Uniform KD | 判断普通蒸馏是否有机会 | 冻结对齐的多模态教师 |
| 类别加权 CE | 排除监督重加权解释 | 保留普通 CE 参照，记录归一化 |
| 类别加权 KD | 复核已有候选 | 与 uniform KD 对比，不能只比 CE |
| 简单教师正确性 KD | 判断拒绝错误目标是否有价值 | 按 foreground 或类别控制背景占比；CE 不关闭 |

先用共同种子、相同预注册的筛选预算运行所有分支，只用于排除实现问题与挑下一阶段候选。短训排名不当作最终 500 轮结论；一个 seed 的筛选不声称显著。

目前最值得优先考察的是两个简单、可解释的候选：类别加权 KD 与教师正确性选择 KD，而不是再添加“教师对、学生错预测器”。后者即便训练期可直接由 GT 获得，也只是选择规则，不等于恢复性机制。

### 阶段三：确认候选，再讨论模态归因

对 CE、uniform KD 和筛选出的候选做配对多 seed 完整训练；类别加权 CE 必须随类别加权 KD 一起保留。三个 seed 可作最低描述性起点，不是功效保证。

记录每个 seed 的方法差值，报告均值、离散程度、区间和单独的图像重采样区间；如需统一区间，采用同时处理训练 seed 与图像/场景的层级方法，并承认小 seed 数限制。

候选有稳定增益后，再补同权重教师无关软目标正则和 RGB 教师 KD，验证特权模态是否提供额外价值。若只得到一般重加权收益，就按一般重加权结论报告，而不包装成 RAPD 的恢复性发现。

### 阶段四：只有必要时才改目标形式

如果固定 logit 候选未改善关键条件性指标，允许探索固定的任务相关特征/关系监督，但仍作为未验证假设。应与固定 logit、无 KD 及相同参数开销对照。

只有发现“不同监督在不同训练可识别群体中有稳定不同收益”，才考虑路由。路由需优于最佳固定通道、随机但同配额路由、学生置信度规则和教师可靠性规则；最终测试无 GT、无真实热特征。

不把旁路作为默认必做项，不保证换通道会成功。

## 11. 停止规则应该怎样写

先依据应用或研究目标预注册最小有意义效应 delta、关键次指标允许的退化范围、预算与多次筛选规则。delta 是项目决策阈值，不是信息论常数。

| 结果 | 正确结论与动作 |
|---|---|
| 方法差值区间全部高于 delta，关键指标不退化 | 在受测设置中有实用增益；继续确认归因与复现 |
| 区间全部落入预定等效范围，且协议与功效合理 | 在该精度/预算下可认为收益不足；停止这条配置路线 |
| 区间包含有价值的正收益与零或负值 | 不确定；按预算决定补 seed 或停止投资，不宣称不可能 |
| 优势预测 AUC 好，但路由训练不改善 | 预测标签不等于收益，停止用 AUC 为路由背书 |
| 旁路移除后失败 | 该旁路训练方案未成功，不证明 RGB 不可达 |

不使用单次“差 < 0.5”自动归零特权贡献，不用固定 AUC 0.6/0.7 或 IoU 53/55 给整条科学路线判死。

## 12. 文献核对：哪些结论被支持，哪些没有

本轮做了针对性的网页与学术检索，不是完整最新方法综述；部分学术源暂时不可用。以下区分全文阅读、摘要阅读与仅元数据核对，不伪称全部复现。

### [1] Revisiting Knowledge Distillation via Label Smoothing Regularization

- Li Yuan 等，CVPR 2020；本轮阅读 arXiv 摘要与元数据。
- https://arxiv.org/abs/1909.11723
- 摘要明确认为 KD 成功不仅来自类别相似信息，也来自软目标正则化。它反驳了我此前“不增加新信息就不可能涨点”的一般推论。
- 不支持本项目 RAPD 一定有效，也不为某个 epsilon 上界提供 mIoU 保证。

### [2] Rethinking Knowledge Transfer in Learning Using Privileged Information

- Danil Provodin 等；本轮阅读 HTML 正文主要章节，包括蒸馏与边缘化定义、训练充分性和架构对照分析、结论。
- https://arxiv.org/html/2408.14319v1
- 文章强调训练时长、架构和数据机制等混杂可能被错误归因于特权信息，支持本报告增加归因对照。
- 文末也明确指出其发现并未最终否定特权知识迁移的可能性。不能用该文把 MFNet 的有限失败升级为普遍不可蒸馏定理。

### [3] Teacher privileged distillation: How to deal with imperfect teachers?

- Mario Martínez-García、Iñaki Inza、Jose A. Lozano；Knowledge-Based Systems，2025。
- https://doi.org/10.1016/j.knosys.2025.113338
- 本轮通过学术检索定位，并用 Crossref 注册记录核对题名、作者和出版信息： https://api.crossref.org/works/10.1016/j.knosys.2025.113338
- 本轮未阅读其完整论文，故不引用其具体效果或公式。它是提醒我们检查“教师可靠性选择”已有工作的相关性线索，而不是声称新路由创新性的依据。

现有文献已经包含软目标正则、特权迁移归因与不完美教师等方向；所以“预测器 + 路由器”作为一句话并不构成新颖性证据。完整论文路线仍需进一步检索与基线对齐。

## 13. 最终建议

**需要调整工作，但不建议直接实现上次给出的改进方案。**

保留：纯 RGB 推理约束、证据保存、类别加权 CE、教师可靠性与背景偏置对照、按图像/场景划分、配对多 seed。

撤回：定义层面永远无效的断言、教师优势标签就是可恢复性、AUC 决定通道、旁路失败证明不可能、少蒸馏收益上界零、保证一天完成且三个 seed 足够、保证负结果能形成顶会论文。

推荐执行顺序：**证据恢复与协议冻结 → 简单选择性/重加权对照 → 候选完整多 seed 确认 → 正则与模态归因 → 必要时固定特征监督 → 最后才考虑学习路由。**

这一顺序可靠的是“能回答清楚什么有效、为什么有效或哪里失败”，不是“保证 RAPD 成功”。若没有稳定增益，就如实报告受测配置的局限，停止继续为 RAPD 名称寻找包装。
